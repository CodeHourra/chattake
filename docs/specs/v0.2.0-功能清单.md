# 寻迹 v0.2.0 功能清单

> 实现日期：2026-08-30；权威边界见 [`../plans/2026-08-30-v0.2.0-架构与功能重构.md`](../plans/2026-08-30-v0.2.0-架构与功能重构.md)。

## 采集与数据安全

- Claude Code、Cursor、Codex、CodeBuddy 四类来源独立解析并统一为标准会话。
- 启动扫描、全局手动同步和按来源同步；扫描本身不调用模型。
- `mtime + size` 预判与内容哈希确认可识别同消息数修改和消息减少。
- 旧 Schema 仅在 `VACUUM INTO` 可恢复备份成功后重建，备份路径会显示给用户。

## API 配置与任务

- 同时保存多套 OpenAI、DeepSeek、Moonshot、智谱、硅基流动或自定义 OpenAI-compatible 配置。
- 模型可刷新、搜索或自由输入；硅基流动使用完整模型 ID，并筛选 chat 模型。
- 每个分析任务保存配置 ID、供应商、Base URL 和模型快照；API Key 只在启动任务时进入内存。
- 任务状态持久化为 `queued/running/succeeded/failed/cancelled/interrupted`，支持取消、失败项重试和异常退出恢复。
- 不自动跨供应商故障转移；重试时可明确选择另一套配置。

## 知识提取与治理

- 每场会话只预处理一次，24,000 字符预算保留完整首尾轮次并均匀采样中段。
- 高价值提取 1–3 项并发布；中价值提取 1–3 项进入草稿；低/无价值仅记录判断。
- 类型固定为 `decision / troubleshooting / implementation / explanation / snippet`。
- 每项最多 3 个主题标签、5 个技术项；支持编辑、标签重命名和事务合并。
- 重新分析始终先生成草稿；发布时可并存或替换，人工编辑知识默认受保护。

## 检索、MCP 与界面

- FTS5 trigram 支持中英文子串；少于 3 字符回退到转义后的受限 `LIKE`。
- 搜索展示命中片段、类型、主题、技术项、价值和来源，默认隔离草稿。
- 只读 MCP 提供 `xunji_search`、`xunji_get_card`、`xunji_list_facets`、`xunji_get_source`。
- MCP 不返回草稿、任务、API Key、供应商配置或完整 Base URL；设置页仅复制配置，不修改外部应用。
- Light/Dark 双主题；液态玻璃仅用于侧栏、顶栏、浮层、配置面板和任务中心；支持窄窗口。
- 会话列表聚合查询、对话 100 条游标分页、设置/Markdown/详情懒加载，生产 Chunk 小于 500 KB。

## 明确不支持

LLM CLI、任何 `*-internal` 路径、自动跨供应商切换、Embedding/向量检索、REST API、远程同步、后台守护进程和模型并发。
